## 本次更新（9.9.0 → 9.9.1）

> **纯热修版本**：无新增功能、**无数据库结构变更**，覆盖解压即生效。

### 问题修复

- **修复燃尽图 500**（9.9.0 起存在）：**工期为 0 的项目**打开燃尽图必然报错 ——
  `projectModel::getByID()` 在工期为 0 时把 `days` 置为空串（为的是界面不显示 0），
  而 `project->burn()` 直接拿它去除 `maxBurnDay`，PHP 8 对 `'' / '31'` 抛
  `TypeError: Unsupported operand types: string / string`。
  现已两侧强制转 int 并保证除数 ≥ 1；`getDateList()` 中的同型表达式一并加固。

### 是否建议升级

- **建议**。新建项目的工期默认为 0，此类项目的燃尽图 100% 报错（老项目工期非 0 故未暴露）。
- 升级方式：可直接覆盖解压（本版无数据库变更）；若站点规范要求走升级流程，用下方 CLI 通道即可。

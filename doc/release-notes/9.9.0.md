## 本次更新（9.8.3_1 → 9.9.0）

> 首个社区定制版发布：**9.8.3 业务内核 + 移植禅道 10.1 界面**。

### 一、界面层（移植禅道 10.1）

- **全新界面**：10.1 应用骨架（页头/导航/页脚）、615 个页面模板、126 个语言文件、皮肤基座整体移植（`feat/ui-101`）。
- **前端框架升级**：ZUI 1.7 → 1.8.1（对齐 10.1，补齐 timeSpanControl 等 API），新增兼容层 `www/theme/default/compat.css` + `www/js/compat.js` 保证老页面正常渲染。
- **三款主题**：WenYin 紫色（默认）/ 亮蓝 / 黑莓；WenYin 由 10.1 purple 基座重制（`#3123ae → #6f42c1` 紫色系映射）。
- **仪表盘新版式**：我的地盘/产品/项目/测试四类仪表盘静默迁移到 10.1 布局（左右分栏、欢迎块统计磁贴、统计块进度环），无需用户确认。
- **移动端全面适配**：三主题通用响应式（仪表盘单栏堆叠、导航横滑、页脚自适应），修复页脚重叠/裁切问题。
- **细节修复**：进度环负半径崩溃、表头排序错位、多行文本框压扁、项目页坏链接、菜单激活态失效等。

### 二、功能特性（自 9.8.3 内核新移植）

- **动态流**（我的/组织/产品/项目/用户，5 处）：按日期分组展示 + 双向翻页（更早/更新），重点动作高亮。
- **文档收藏**：星标收藏/取消文档与文档库，新增「我的收藏」浏览入口与首页统计。
- **文档统计**：文档首页统计卡（所有文档/今日更新/最近更新进度环）。
- **父任务日期自动汇总**：子任务日期变更自动回写父任务（最早开始/最晚截止）。
- **项目概览统计**：项目概览页展示关联需求/任务/Bug 数量与燃尽图。
- **待办批量关闭**：我的待办支持勾选批量关闭（独立权限点）。
- **测试报告图表**：测试报告页展示用例结果/类型/模块/执行人分布图。
- **项目树状图**：树状视图节点渲染 + 右侧需求/任务详情面板。

### 三、平台能力（v9.9.0 全量包含）

- **MCP 集成（zentao-mcp）**：63 个工具覆盖任务/需求/Bug/项目/产品/计划/发布/测试/文档全生命周期；git 提交驱动工作流（`task #N` 标记联动）；双层 MD5 签名鉴权 + 个人密钥体系（防冒充署名）+ 写入审计。
- **统一认证（SSO）**：接入 wenyinos 认证中心，登录/登出/改密全域同步，支持组准入控制。
- **升级流程（社区版单通道）**：仅支持 9.8.3_1 及后续社区版本升级；官方禅道数据库会被明确拒绝，防止数据损坏；支持 CLI 升级通道（免放开 Web 入口）。
- **发布自动化**：本包由 GitHub Actions 自动构建（全量 lint + 版本三重校验 + 包内容断言 + SHA256 校验和）。

### 四、问题修复

- 修复游客访问仪表盘被权限守卫掐断导致页面半截的问题。
- 修复移动端页脚版权信息与面包屑重叠/不可见的问题。
- 修复文档模块「界面已就位、后端缺失」的系列断链（收藏按钮报错、统计空白等）。
- 修复页面左上角切换器（项目/产品/分支/用例库/模块）点击无响应且错位的问题：改用 10.1 的 ZUI `dropdown + search-list` 机制（ajax 加载 + 即时过滤），并清理 `compat.css` 中冲突的旧 `#dropMenu`/`#currentItem` 规则。
- 修复产品页、用例库页切换器整块缺失的问题（旧实现注入的菜单键在 10.1 语言包中已不存在）。
- 修复用例库切换器的 ajax 下拉报「The param 'extra' should pass value」（`testsuite`/`tree` 的 `ajaxGetDropMenu` 补默认参数）。

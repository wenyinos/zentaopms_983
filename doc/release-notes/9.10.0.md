## 本次更新（9.9.1 → 9.10.0）

> 本版为 **22.6 功能移植批次**的交付版本；含新增数据库表，**升级需执行升级脚本**（见下方 CLI 通道）。

### 一、新功能

- **看板升级**：泳道维度扩展为 需求 / 模块 / 指派人 / 优先级；支持**同列拖拽排序**（顺序按泳道维度分别保存在 `zt_config`，零表结构变更；跨列拖拽仍走状态流转表单，不绕过状态机）；泳道可折叠（状态只存浏览器本地）。
- **用例库导出**：用例库支持**按当前浏览条件或勾选导出 CSV**，字段与导入模板同构（`步骤`/`预期` 成对），可"导出 → 修改 → 再导入"闭环；附件列输出「标题 + 可下载地址」；列表页新增「导出用例 / 编辑库 / 删除库」入口。

### 二、问题修复（本版独有）

- 修复用例库删除时报 `Attempt to read property on null`（控制层未先取 `$suite` 对象）。
- 修复文档目录内的文档在文档库「全部」视图不显示、「所有文档」统计少算（`getPrivDocs` 对齐 22.6 写法）。
- 版本号规则放开为支持 `9.10.0` 形式（仍拒绝官方禅道版本）。

### 三、平台/兼容

- 新增 helper 6 个（`setcookie`/`hasFeature`/`arrayColumn`/`formatHours`/`isApiRequest`/`mbPathinfo`），供后续移植使用。
- 引入 **eCharts 5.5.1 全量构建**（Apache-2.0，1.03MB）——注意不能用 `common` 构建，其不含 radar 类型。
- 首次按 §1.4 的升级约定引入**幂等建表**（后续里程碑 M2 起会新增 `zt_errorlog` 等表）。
- 已包含 `main` 的 9.9.1 热修（燃尽图 500）。

### 升级提示

- 本版**有数据库变更**（后续 M2 起逐步加入），请按下方 CLI 通道执行升级；如站点规范要求，先备份数据库。
